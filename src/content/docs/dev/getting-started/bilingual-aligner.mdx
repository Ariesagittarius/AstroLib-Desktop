## 1. 核心理念与体验范式

在经典的教材翻译与跨语言学术阅读中，读者经常需要在**英文原著**与**中文译本**（甚至不同时期的多个中译本）之间频繁对照，以核对专业术语、定理推导细节与公式符号。

AstroLib 拒绝让用户在跳转外挂页面或切屏中打断阅读心流，实现了**当前正文内联展开的 50%-50% 响应式双语对照系统**：
- **正文即对比**：点击章节顶部的 `双语段落关联对比` 按钮，直接在当前页面平滑将主阅读区展开为左右等宽双栏。
- **全保真学术排版**：左侧与右侧均完整保留 KaTeX 独立行内/块级公式、定理卡片、`<Algorithm>` 伪代码容器与高清插图，排版高度一致。
- **跨中缝贝塞尔曲线连线**：基于双向语义计算，鼠标悬停于任一侧段落时，中缝画布自动绘制平滑的 SVG 三次贝塞尔曲线（Cubic Bézier Curve），直观指引对侧对应的译文。
- **关联度热力图底座**：底部可唤出学术级相关矩阵热力图（Sequential Blues），呈现全章段落余弦相似度分布并支持阈值滑块实时过滤。

系统由四层松耦合模块协同运作：

└─────────────┬────────────────────────────┬─────────────┘

## 3. 核心子系统实现原理

### 3.1 多模型向量嵌入与自适应分流 (`BilingualOnnxEngine` & `QwenEngine`)

系统采用多层次可选模型架构，以适配从轻量学习本到高配置工作站的差异化设备环境：

1. **基准轻量级模型（默认，MiniLM-L12）**：
   - **模型**：`Xenova/paraphrase-multilingual-MiniLM-L12-v2`（INT8 `q8` 量化，384 维向量，约 117MB）。
   - **零门槛运行**：纯 Node.js CPU/AVX2 原生推理，彻底免去 GPU 与 Python 环境配置，对整章 134 个长段落仅需约 10 秒。
2. **高精度大参数模型（可选，Qwen3-Embedding-0.6B）**：
   - **模型**：`Qwen/Qwen3-Embedding-0.6B`（0.6B 参数 CausalLM 架构，1024 维向量）。
   - **突破各向异性锥状坍缩**：基于大语言模型自回归注意力与 Last-Token Pooling，无关文本跨领域相似度大幅压制至 0.15~0.25（对比 E5 系列 0.83 的各向异性底噪），真正提供高对比度的语义分辨力。
   - **常驻 Daemon 零重载**：后台启动 Python 常驻子进程（`qwen-runner.py --daemon`），初次加载后显存常驻（占用约 1.2GB VRAM），请求端到端耗时降低至几十毫秒。
   - **零外部流量保护**：严格锁定本地本地缓存权重（`local_files_only=True` 与 `HF_HUB_OFFLINE=1`），杜绝代理流量消耗。
3. **前端热力图一键无缝切换**：
   - 在底部的关联度热力图（Alignment Heatmap）控制栏中，提供 Material 3 风格的双模型筛选芯片（`MiniLM (轻量)` / `Qwen3-0.6B (高精)`），点击即自动触发自适应重算并重绘 SVG 贝塞尔中缝连线。

### 3.2 最优二分图贪心对齐 (`BipartiteMatcher`)

针对中英文段落长度不对等、OCR 断行差异及翻译合并/拆分现象，算法基于余弦相似度矩阵进行二分匹配：
1. 过滤低于设定阈值（默认 0.45~0.50）的低置信度噪点；
2. 优先锁定全局最大相似度段落对；
3. 结合段落空间相对位置约束，防止大幅度越界交织错位；
4. 输出左右段落的清晰映射关系集合。

### 3.3 侧栏状态智能记忆与无损复原

遵循系统架构第 7 条规范（Sideload 侧载底座规范与多视口自适应）：
- **进入对比**：双栏需要充裕的水平视口空间，控制器记录当前左侧目录大纲与右侧 Sideload 面板的展开状态，自动收起两侧栏，正文平滑伸展为 50%-50%；
- **退出对比**：读者点击 `退出对比` 或按下键盘 `Escape` 键时，页面并非盲目重新全部展开，而是精确回滚至进入对比前的状态。

### 3.4 颜色与层级令牌守卫

全套样式完全消费 Material You 官方设计令牌：
- 退出按钮、切换芯片与控制栏使用 `var(--md-sys-color-primary)`、`var(--md-sys-color-surface-container-high)` 等语义色，主题切换（浅色/深色）无缝自适应；
- 窗口层级严格消费 `--layer-popover` (300) 与 `--layer-local-elevated` (5)，严禁出现破坏视窗叠放顺序的任意 `z-index` 魔数。

## 4. 真实教材教学逻辑错位分析与重构规范

在实际工程中，算法段落对齐效果不仅取决于语义相似度计算，更受限于**教材译本与原著在教学阐述逻辑上的结构性分歧**。以经典算法教材 DPV《Algorithms》第 2.6 节《快速 Fourier 变换》为例：

### 4.1 典型错位现象

1. **动机灰色导引框错位**：
   - 原文在正文开头以灰色底框给出 FFT 算法的思想萌芽与启发式引言；
   - 某中译本排版时将该导引框移到了正文第 2 小节下方，导致引言段落产生大幅度物理距离跳跃。
2. **孤立过渡句被错误合并**：
   - 某些关键递推公式的衔接过渡句被并入前一段落，导致跨语言断句粒度失真。
3. **扫描 OCR 伪 H2 标题打碎段落**：
   - OCR 误将重点加粗句子识别为 `##` 标题，切断了 Markdown 段落流。

### 4.2 重构原则与规范

- **原著教学逻辑为准绳**：在不改变数学结论的前提下，调整译文 MDX 的块级结构，使其阐述顺序、动机导引、定理边界与原版严格呼应。
- **统一伪代码容器**：算法流程统一收敛至 `<Algorithm>` 容器，公式统一使用标准 KaTeX 环境，保持左右两栏视觉高度均衡。

node scripts/run-alignment-diagnostics.mjs
