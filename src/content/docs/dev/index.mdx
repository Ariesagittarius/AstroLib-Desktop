## 先说明两件事

- `src/config/collections.config.ts` 是书籍目录与多语言版本的唯一来源；`src/config/features.config.ts` 是全站功能开关的唯一注册表；严禁另建平行的配置。
- `public/` 只放浏览器直接访问的静态资源（严格遵守公共目录卫生规范）。构建产物、临时日志、测试文件与导出中间产物请放在系统临时目录或脚本约定目录，严禁写入 `public/`。

## 贡献前的最低检查

```powershell
npm install
npm run check:types
npm test
npm run build
node scripts/scan-mdx.mjs src/content/docs/collections/<collection>/<book>
```

代码提交前必须执行全站质量门禁 `npm run check:all`，确保 TypeScript 严格类型 0 错误且 Vitest 自动化测试套件全量通过。如果只修改文档页面，至少运行 `npm run build`，确认 Starlight 侧栏和 MDX 均可编译。
