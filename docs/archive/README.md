# Historical Documentation Archive

This directory preserves historical audits, signoff evidence packages, milestone handoff notes, and superseded architecture/workflow documents created during the early evolution of AstroLib.

These files are kept strictly as immutable historical records and **must not** be treated as authoritative guidance for current architecture, active features, security invariants, or testing workflows. Consult the active documentation in [../README.md](../README.md) instead.

## Directory Structure

- `audits/` — Historical phase audits, typography/memory audit reports, and the third-party review archived in November 2026.
- `evidence/` — JSON release and phase signoff evidence packages (e.g., `p0-final-evidence.json` referenced by release metadata contract checks).
- `handoffs/` — Historical feature implementation and textbook migration handoff notes.
- `legacy-architecture/` — Superseded Web/Starlight architecture specs, legacy ADRs, quickstarts, and migration logs prior to the Electron + ABP + Harness consolidation.
