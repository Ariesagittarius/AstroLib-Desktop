## 4. 须补正项（P1-A1 开工前）

### F1（阻断）证据格式缺失
§6.7 明确要求“验收命令与**证据格式**”，ADR §7 只给了指标阈值，没有定义 evidence 落盘路径与字段。
**要求补正**：新增 §7.3，规定 `docs/architecture/evidence/p1-a-evidence.json` 的字段（`gate` / `baseCommit` / `commands[]` / `exitCodes[]` / `books=13` / `chapters=1251` / `slugMismatch=0` / `legacyCovered=1195` / `notFoundProbe={status,contentType,bytes}` / `artifactSha256[]`），格式对齐 [`p0-final-evidence.json`](./evidence/p0-final-evidence.json)。

### F2（阻断）Web 端 canonical 路由口径二义
ADR §2.1 把官方章节的 Web 提供方写成“Universal Reader SPA 路由 `/collections/...`”，但 §6 Step 3 只规划 `/reader/` 骨架，§4.3 又称“逐步替代”。三处合起来无法判定 P1-A 的验收边界。
**要求补正**：用一句话定死 P1-A 是否包含 Web 静态 `/collections/` 路由。建议明确：**P1-A 不做 Web 静态 1,251 章路由**（§2.1 表格该行改为“Web：P1-A 阶段 404/明确空态，静态路由由 P1-A3 运行时入口承接，SEO 静态化另行立项”），否则 §6.4 的“1,251 章无 404”在 Web 端不可验收。

### F3（阻断）上传书路由规则自相矛盾
§2.1 写“绝不为上传书生成静态路由”，§2.2 第 3 点又允许桌面端对 `userAbpDir` 提供 `/collections/...`；而现有代码 [`static-handler.ts:324-326`](../../electron/server/static-handler.ts#L324-L326) 确实让 `userAbpDir` 命中 `/collections/`。
**要求补正**：给出可检验的判定，例如“`/collections/:col/:book/:chapter/` 仅由官方 artifacts 目录（`resolveAbpArtifactsDir`）服务；`userAbpDir` 一律 301 到 `/reader/?book=...`”。若采用此严格口径，P1-A1 必须同步删除 userAbpDir 分支并补测试；若保留同构服务，则须写明“运行时同构 ≠ 构建期静态路由”，并给出 404 与重定向矩阵。

### F4（阻断）与 `AGENTS.md` §8.2 的冲突未声明
`AGENTS.md` §8.2 把“桌面端章节阅读基于 `dist/reader-shell/index.html` 预编译 Starlight Master Shell，在 `reader-shell-template.ts` 中动态装配”列为**铁律**；ADR §4.3 要求 Starlight 退出正文阅读器。执行端读到互相矛盾的规则时会触发 §6.8 停止条件。
**要求补正**：在 ADR §4.3 增加“规则冲突与生效顺序”小节，明确：P1-A~P1-D 期间 `AGENTS.md` §8.2 仍有效（`reader-shell-template` 的合成机制不动，P1-A2 只净化其生成的 slug 链接）；§8.2 的废止或改写统一在 P1-E 文档治理 Wave 处理，并列出需改写的条款号。

### F5 别名语义与 301 落点未定死
实测 `legacySlug` 只在 `raw !== canonical` 时写入（1,195/1,251）；`00_preface` 等 56 章 `legacySlug` 为 `undefined`，老外链的 `.mdx` 形态只能靠 [`static-handler.ts:342-348`](../../electron/server/static-handler.ts#L342-L348) 的 canonical 候选兜底。
**要求补正**：写明“legacy 表仅覆盖 raw≠canonical 的 1,195 章，其余以 canonical 自身为唯一合法路径”；并指定 301/URL 规范化的实现位置（桌面端 301 响应头 + `resolvedSlug` 回填，Web 端 `history.replaceState`），以及在 `synthesizeAbpHtml` 缓存键中使用 `resolvedSlug` 的规则。

### F6（P2，可随 A1 补）行号漂移与 404 视窗无最小规范
- ADR §1.1 称 `pack-book-abp.mjs` L570–628，实际 slug 逻辑在 L559–626；`FragmentReaderHost` URL 生成在 L213（ADR 写 L209–217）；
- `src/pages/` 清单漏 `workspace/ingest.css`；
- 404 视窗只写“友好/学术”，未给最小规范。现网行为是 `404 text/plain`（`local-server.ts:192-193`）。
**要求补正**：补 404 视窗最小规范：HTTP 状态 404、`Content-Type: text/html; charset=utf-8`、标题与“返回书库/大纲”入口、复用现有 tokens（禁止新增视觉语言）、以及覆盖它的断言方式。
