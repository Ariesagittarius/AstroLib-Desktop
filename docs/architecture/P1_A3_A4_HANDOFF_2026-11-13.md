### 5.1 `tests/contract/reader-routability.test.ts`（核心交付）

必须遍历 **全部** 13 个 manifest（数据源 `artifacts/abp-packs/*/manifest.json`），并以 `StaticHandler.handle()` 的**实际返回状态**做断言，不得以 `fs.existsSync` 代替：

1. 每个 `chapter.slug` → 期望 `200` 且 `Content-Type` 含 `text/html`（**1,251 条**）；
2. 每个 `chapter.legacySlug` → 期望 `301` 且 `Location` 以 `/${canonicalSlug}/` 结尾（**1,195 条**，允许 Windows 大小写不敏感导致 ≤5 条为 `200`，须显式记录而非忽略）；
3. 每本书 `entryPoint` 必须存在于章节集合（**13 条**）；
4. 抽样 3 条伪造 slug（含多级 `zh-wp/` 形态、`07_1/` 前缀）→ 期望 `404` 且 `text/html`；
5. 断言 `static-handler.ts` 源码中 `cleanSlug(`、`normalizedTarget`、`targetNorm` 匹配数为 **0**。

**性能约束**：整文件 < 90s（可用 `beforeAll` 复用 handler 实例；缓存由 StaticHandler 自身负责）。若超时，改为“每本书取 100 章 + 每本书全部 legacy”并在报告说明，不得整体 skip。

### 5.2 404 视窗对齐 ADR §7.2（F4 收敛）

- 图标：Material Symbols 内联 SVG（`menu_book` 或 `error_outline`），**不得**用 emoji/字符 `⚠`，不得新增图标库；
- 按钮：`返回研读书库`（`postMessage` 到父窗口，保留现有 `astrolib:switch-fragment` 协议）与 `返回默认章节`（指向 `manifest.entryPoint`，无 manifest 时回 `/desktop/`）；
- token：沿用现有 `--md-sys-color-*` 变量名，但**必须在 `prefers-color-scheme` 之外支持页面级 `data-theme`**（可从 `?theme=dark` 读取一次，缺省跟随系统），避免桌面深色模式下 404 刺眼；
- 断言：`404` 视窗必须包含 `Content-Length`、`Cache-Control: no-cache`、诊断三行（合集/书籍/章节）、两个按钮的 `href`/`data-action`。
